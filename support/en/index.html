2. Feedback during the beta

The quickest way is TestFlight:

  • Take a screenshot, then tap “Send Beta Feedback” in the preview. You can mark what caught your eye and add a sentence.
  • Crash: After a crash, TestFlight asks whether to send a report. A sentence about what you were doing helps a lot.
  • Everything else (ideas, what is missing, what bothers you): by email.

PersOS itself collects no usage data, no analytics and no tracking. I only see what you send via TestFlight or email.

3. What matters in the beta

  • Does the app feel calm for newcomers, or is it too much?
  • Does the setup fit your stage of life (school, university, work)?
  • What do you miss, what bothers you day to day?
  • Where does it get stuck: something takes too long, a button does not respond, a text is unclear?

4. Frequently asked questions

Do I need an account?

No. PersOS works fully without an account. You only need an account or iCloud if your data should stay in sync across devices.

How do I back up my data?

In Profile and Settings → Data & Backup you export an encrypted backup to the Files app. Keep the passphrase safe: it cannot be recovered.

I lost the recovery code for sync.

As long as one device is still set up, you can create a new code there (Settings → Connections). If all devices are gone and the code is lost, the data on the server can no longer be decrypted. That is on purpose: nobody but you can read it.

The widgets stay empty.

Open PersOS once. The app then writes the state the widgets show.

How do I delete my account?

In Profile and Settings → Connections → Delete account. Your data on the device stays.
